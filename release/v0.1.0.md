# v0.1.0 — 首个发布版

日期：2026-10-11 · 分支：`v2/clean-room` · 真源 HEAD：见 `git log -1`

## 这是什么

麒麟仔 vs 鲸鱼娘 —— 跑在 DSH Web UI 里的**双宠同台桌宠**插件。clean-room 原创实现：
机制参考 PC2005-cloud/dsh-pet（MIT）的公开设计思想，**零上游代码/素材/文案**；
角色资产（麒麟仔、鲸鱼娘「汐」）由本仓图像管线生成。

## 功能面

| 面 | 内容 |
|---|---|
| 舞台 | 双缓冲透明视频交叉淡入 · 位移权威世界 · 拖拽/点击手势（左键点击反应池不连播，阈值 5px） |
| 关系 | 关系账本跨会话（host 独占写 / 原子落盘）· 合演剧本 8 个（声明式编排 + 原创文案）· 心智效用打分 · 导演四阶段仲裁 |
| 诱因 | 真宿主事件（turn-fail / turn-ok / waiting）+ **执行期活动**（agent/status、tools/pre-execute → 按工具类别冒「在翻文件 / 在跑命令…」，host 侧合并防刷屏） |
| 余额 | 服务端代查联合类型（诚实降级，绝不伪造数字）· 余额档位播报 |
| 生命周期 | 舞台挂宿主槽位 `shell.overlay`（inject: slots）—— **禁用即卸载**，无孤儿 DOM |

## 安装 / 卸载

```bash
dsh plugin --profile web add dsh-kylin-pet      # 安装（npm）
dsh plugin --profile web remove dsh-kylin-pet   # 卸载
```

装完刷新页面。镜像分发：dsh-plugins 仓 `dsh-kylin-pet/` 子目录（`npm run sync:mirror` 同步）。
