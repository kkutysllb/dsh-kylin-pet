日期：2026-10-11 · 分支：`v2/clean-room` · 基线：v0.1.0（6477800）

## 这一片做了什么

三条线：① v0.1.0 全量功能审计（对照参考实现的机制清单逐条走查）坐实的 **3 红 3 橙 6 黄** 全部修掉；
② 新增**会话跟随**与**任务跟随**——桌宠只对「你正在看的会话」的动静作反应，待办清单与后台任务的三个边界（接活/进度/收工）都有可见反应；
③ 补上**设置页**（体型/位置/余额播报），配置不再只能手改 JSONC。

## 新功能

### 会话跟随（F1）
- 「当前会话」= 最近一条**用户写的消息**所在的会话（`api-session/activity`，子代理与定时任务不发它）。
- host 侧给每条诱因打上来源会话并**过滤**：别的会话开跑/收工/报错不再惊动桌宠。
- 兼容口径：本进程还没见过任何用户消息前不过滤（行为同 v0.1.0）；第一条消息落地后开始跟随。
- 自愈底线：180s 无任何诱因则解除忙碌标记（防「别的会话的收工永不到达」卡死）。

### 任务跟随（F2）
- 待办：`todo_write` 签名去重 → `task-start`（接活了）/ `task-progress`（3/7）/ `task-done`（收工！）。
- 后台任务：`ctx.get('jobs')` 优雅探测（不进 inject）→ registered/settled 上板（只认有主任务；kill/teardown 带后缀）。
- 文案全原创；主讲 = 出厂导演表的 ok 线；诱因不点播的红线不动。

### 表情包气泡（S4）
- 新增 `GET /memes/<petId>/index.json`；气泡按清单升级成图（kylinzi 9 张即刻生效），
  清单为空回退文字（鲸鱼娘素材到位即自动亮，不改代码）。

### 设置页（S5）
- `settings.section` 槽位：每只宠的体型（120-560）/ 位置（四角）/ 余额播报开关。
- `PUT /config` 白名单整形，坏值回 400 带人话；写用户覆盖层 `main-config.jsonc`（原子落盘）。
- 覆盖层的 cast 落盘时**整表按 id 补全**——单宠 patch 不会把另一只挤掉，覆盖层始终是完整可读的一份。
- 体型/位置在舞台启动时定死：保存后点「刷新页面生效」。

## 升级与兼容

- 覆盖层 `cast` 语义不变（整组替换），但本版起设置页写出的覆盖层**始终是完整一表**；
  手写覆盖层仍需自带全部字段（与 v0.1.0 一致）。
- 素材响应带 1h 缓存：手动覆盖同名素材最多脏 1 小时（刷新强刷可绕过）。
- `/state` 诱因多一个 `session` 字段（留证）；旧客户端无感。

## 真机清单（装好后过一遍）

1. 让子代理/别的会话跑活：当前会话的桌宠不应插话。
2. 建一张待办清单跑任务：接活 → 进度（n/m）→ 收工 三个气泡按序出现。
3. 后台任务（如镜像同步挂后台）：开始与完成各一次反应。
4. `/pet reset` 后不刷新页面：下一次互动的落账应从 0 起算。
5. 设置页改体型/位置/余额播报 → 刷新生效；改坏值（如体型 42）应被 400 拒绝并提示原因。
6. 关插件开关：桌宠消失，且关闭前未提交的关系事件仍落账。
